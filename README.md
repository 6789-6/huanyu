# Huanyu

Huanyu is a sign-language learning and interaction project that combines a web learning platform, gesture-based practice, realtime recognition services, and model-side algorithm experiments. The project focuses on improving sign-language learning accessibility through visual course guidance, interactive exercises, and computer-vision-assisted feedback.

## Project Overview

The system is organized around three main parts:

- Frontend learning platform: provides course browsing, practice paths, question pages, translation entry points, and a gesture interaction game.
- Backend algorithm service: provides API logic for sign-language recognition, dataset loading, model invocation, and training or testing support.
- Machine learning modules: include gesture recognition models, realtime inference scripts, keyword classification, boundary detection, and CorrNet-related experiment adapters.

## Main Features

- Sign-language study module with structured learning pages and practice flow.
- Realtime gesture recognition and inference support for interactive scenarios.
- Gesture interaction game with a collapsible dashboard to reduce visual obstruction during practice.
- Algorithm service code for model loading, dataset processing, and recognition result handling.
- Public-safe project scripts for lightweight deployment and local preview.
